# Exanima — русификация для версии 0.9.5.2g

Русский перевод Exanima для актуальной версии игры: тексты предметов, записок, книг и писем,
кириллические шрифты и набор скриптов, который собирает всё это и ставит в игру.

Проверено на: **Exanima 0.9.5.2g (Steam)**

Автор: [LurkMuar](https://github.com/LurkMuar)

## Что сделано

**Перевод**
- Переведены все **183 строки**, которые появились в игре после 0.8.3 или изменились: новые предметы,
  описания способностей, записки, письма и книги.
- **48 строк переведены и вычитаны вручную** — все сюжетные письма, дневники и книги
  (переписка Середина, записи Корлиана, «Пути тауматурга» и др.), а также исправления ошибок машинного перевода.
- Составлен **глоссарий** терминов и названий снаряжения (стёганая рубаха, поддоспешник, альшпис,
  Инверсия, Непрерывность, Единение…), чтобы одинаковые вещи везде назывались одинаково.
- Перевод прошлых версий (~1200 строк) **восстановлен для новой версии**: строки, которые разработчики
  перенесли в другие файлы, найдены и подставлены заново — стандартное сопоставление их теряло.
- Итог: **в текстах `Resource.rpk` не осталось ни одной английской строки** (1378 строк файла).

**Шрифты**
- Разобран формат шрифтов текущей версии: найдены ресурсы `RAYFORM06R…16R_RFI` внутри `Exanima.exe`,
  кириллические шрифты вшиваются точно в них с исправлением таблицы ресурсов.
- **Пересобрана таблица глифов.** В новой версии её записи выросли с 588 до 608 байт и в ней
  появились новые шрифты, поэтому старая таблица ломала весь текст в игре. Скрипт берёт таблицу
  самой игры и переносит в неё данные кириллических символов по записям.
- Подобран межбуквенный интервал отдельно для латиницы и кириллицы (`-SpacingLatin`, `-SpacingCyr`).

**Сборка**
- Конвейер из скриптов: извлечение текста → сопоставление → перевод новых строк локальной моделью
  (с глоссарием, образцами и проверкой служебных меток) → сборка → вшивание шрифтов → установка/откат.
- Перед каждой записью в exe скрипт проверяет, что на месте именно то, что ожидается,
  и останавливается, если игра обновилась.

### Известные проблемы

- Изредка экран моргает чёрным (замечено при наведении на предметы). Причина не выяснена.
- Кириллические шрифты пиксельные и отличаются по стилю от оригинальных.
- Лишний промежуток после некоторых латинских букв (`I`, `W`) в интерфейсе.
- Плейсхолдеры `{®Exanima.Unknown.HeShe}` и т.п. подставляют английские местоимения, пока не переведён exe.

## Что понадобится

1. Exanima 0.9.5.2g (Steam).
2. Установщик русификатора **ZoG Forum Team v1.3.2** (PlayGround, раздел файлов Exanima) —
   из него берутся утилиты распаковки, кириллические шрифты и перевод прошлых версий.
   Сами эти файлы в репозиторий не входят.
3. [innoextract](https://constexpr.org/innoextract/) — распаковать установщик без запуска.
4. Windows PowerShell 5.
5. *(необязательно, только для перевода новых строк)* LM Studio + модель `ai-sage/GigaChat3.1-10B-A1.8B-GGUF` (Q8_0).

Файлов игры в репозитории нет.

## Структура рабочей папки

Скрипты по умолчанию работают с `D:\exanima-ru` (параметр `-Root`) и игрой в
`D:\SteamLibrary\steamapps\common\Exanima` (параметр `-Game`).

```
D:\exanima-ru\
├── backup\         чистые Exanima.exe и Resource.rpk (копия из игры, не трогать)
├── game\           рабочие копии Exanima.exe и Resource.rpk
│   └── patcher\    содержимое app\patcher из установщика ZoG
├── steam-original\ создаётся install.ps1 — для отката
└── <этот репозиторий>
```

## Сборка

```powershell
# 0. Подготовка
mkdir D:\exanima-ru\backup, D:\exanima-ru\game
$g = "D:\SteamLibrary\steamapps\common\Exanima"
Copy-Item "$g\Exanima.exe", "$g\Resource.rpk" D:\exanima-ru\backup\
Copy-Item "$g\Exanima.exe", "$g\Resource.rpk" D:\exanima-ru\game\
innoextract.exe -d D:\exanima-ru\extracted <установщик ZoG>.exe
Copy-Item D:\exanima-ru\extracted\app\patcher D:\exanima-ru\game\patcher -Recurse

# 1. Восстановить заголовки утилит распаковки (в установщике они намеренно испорчены)
powershell -ExecutionPolicy Bypass -File .\scripts\00_unhide_tools.ps1

# 2. Извлечь текст и сопоставить с переводом прошлых версий
Copy-Item .\patcher\extract.bat D:\exanima-ru\game\patcher\
cmd /c "D:\exanima-ru\game\patcher\extract.bat < nul > D:\exanima-ru\game\patcher\extract.log 2>&1"

# 3. Восстановить перевод строк, переехавших в другие файлы
powershell -ExecutionPolicy Bypass -File .\scripts\stage1.ps1

# 4. Сборка: текст -> Resource.rpk -> шрифты -> установка в игру
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

Переводы новых строк уже лежат в `data/` — шаг с моделью не нужен.
Чтобы перевести новые строки самому (например, после обновления игры):
запусти LM Studio, затем `scripts\stage2.ps1` и в `build.ps1` / `stage3.ps1` укажи
`-Stage2 D:\exanima-ru\game\patcher\results_stage2.tsv`.

### Откат

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Restore
```

Или Steam → Exanima → Свойства → Установленные файлы → Проверить целостность.

## Как это устроено

- **Текст.** Строки из `Resource.rpk` извлекаются в построчный `resource.txt`.
  `stage1` восстанавливает перевод прошлых версий по всему файлу, `stage2` переводит новые строки
  локальной моделью (глоссарий, похожие образцы, защита служебных меток `\r\n`, `\x10`, `[sq]`, `{®…}`),
  `stage3` собирает итог и накладывает ручные переводы из `data/overrides.tsv`.
  Файл сохраняется в Windows-1251.
- **Шрифты.** В текущей версии exe перед шрифтами появились три новые картинки, поэтому старый способ
  вставки шрифтов попадал не туда. `fonts_patch.ps1` кладёт каждый шрифт в свой ресурс
  `RAYFORM06R…16R_RFI` и правит его размер в таблице ресурсов.
- **Таблица глифов.** Записи выросли с 588 до 608 байт, в таблице появились `fontbase24r` и `titlefont`.
  Скрипт оставляет формат и параметры игры и переносит только данные символов, затем добавляет
  интервал `-SpacingLatin` / `-SpacingCyr`.
- **Кириллический `titlefont.rfi` не используется:** в нём латинские заглавные перерисованы под кириллицу,
  и английское меню превращается в набор русских букв.

Смещения в exe привязаны к сборке 0.9.5.2g. Найти новые после обновления игры: `scripts\pe_res.ps1`.
